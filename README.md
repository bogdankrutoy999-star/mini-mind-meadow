# Mini Mind Meadow

Create a complete AI assistant website called Mini.  DESIGN: - Modern dark interface inspired by ChatGPT. - Purple and blue gradient accents. - Cute 3D robot logo. - Sidebar with chat history. - New Chat button. - Main chat area with message bubbles. - Message input with send button. - Image generation button. - Settings page with light and dark themes. - Responsive design for desktop and mobile.  FUNCTIONALITY: - Real AI chat powered by Google Gemini API. - Use a server-side API route. - Read GEMINI_API_KEY from environment variables. - Never expose the API key in frontend code. - Support general questions, programming, explanations, brainstorming and normal conversations. - Maintain conversation history. - Add loading indicators and error handling. - Prepare a separate image generation feature for future integration.  TECHNOLOGY: - Next.js - TypeScript - Tailwind CSS - Secure server-side Gemini integration.  Do not use fake AI responses or predefined answers.
